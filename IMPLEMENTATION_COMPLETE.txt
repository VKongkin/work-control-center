STEP 1: Install Docker Desktop
  ↓
  1. Download from: https://www.docker.com/products/docker-desktop
  2. Choose Mac version (Apple Silicon or Intel)
  3. Install and launch
  4. Verify: docker --version

STEP 2: Start the Application
  ↓
  cd "/Users/macbookpro/Documents/Work/SBI Bank/Tool/work-control-center"
  docker compose up -d --build
  
  OR use Makefile:
  make up

STEP 3: Wait for Services
  ↓
  docker compose ps
  (Wait for "healthy" status on all 4 services - ~60 seconds)

STEP 4: Access Application
  ↓
  Frontend:   http://localhost:3000
  API Docs:   http://localhost:8000/docs
  Database:   http://localhost:8080

  ↓
  • Browse dashboard statistics
  • Create tasks and follow-ups

  • Check API documentation
